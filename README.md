# HR Workforce Analytics Dashboard

## Project Overview

This project uses Power BI to explore employee engagement and
workforce patterns through interactive visualizations.

The report examines employee satisfaction, workload, performance
evaluations, promotion patterns, and departmental differences.
It is designed to support exploratory analysis and inform
workforce planning discussions.

## Project Objectives

- Explore how employee satisfaction varies by workload.
- Compare satisfaction and performance evaluations across departments.
- Examine employee distribution and promotion patterns by satisfaction level.
- Identify workforce patterns that warrant further investigation.

## Tools Used

- Power BI Desktop
- DAX
- Data visualization

## Dashboard Pages

### 1. Overview

Provides a consolidated view of employee count, departmental
distribution, satisfaction, workload, performance evaluations,
and promotion patterns.

### 2. Workforce Trends

Provides a focused view of:

- Average satisfaction by workload level.
- Satisfaction and performance evaluations by department.
- Employee count and promotion patterns by satisfaction level.

## Selected Observations

- Employees in the medium-workload category show higher average
  satisfaction than those in the low- and high-workload categories.
- Employees in the high-workload category show the lowest average
  satisfaction among the three workload groups.
- Average satisfaction and performance evaluation scores vary
  across departments.

These observations describe patterns in the dataset. They do not
establish that workload or department causes changes in satisfaction.

## Dataset

This project uses the Employee HR Dataset published by Prisha Tank
on Kaggle.

Each row represents an employee record. The dataset includes
information on employee satisfaction, performance evaluations,
project workload, monthly working hours, tenure, promotions,
department, salary, and employee attrition.

The publisher describes the dataset as simulated HR data without
personally identifiable information. It is used here for educational
analysis and portfolio demonstration, rather than to represent
findings about a verified organization.

Source: [Employee HR Dataset — Prisha Tank, Kaggle](https://www.kaggle.com/datasets/prishatank/employee-hr-dataset)

Dataset license: CC BY-SA 4.0.

## Limitations

- The report presents descriptive patterns rather than validated
  predictions of employee turnover.
- Findings depend on the dataset's quality, definitions, and coverage.
- Associations should not be interpreted as causal relationships.
